<h2>Introduction</h2>

Fallout 4 VR is not a great experience out-of-the-box. You exist as a pair controllers floating mid air, VATS is terrible, and the game is built on an outdated version of the game that doesn't include DLCs or many bug fixes. Thankfully [FRIK](https://www.nexusmods.com/fallout4/mods/53464), [Kabuto VR](https://www.nexusmods.com/fallout4/mods/35909), [Daytripper 4](https://www.nexusmods.com/fallout4/mods/91141)﻿, and many more amazing mods make the VR experience far more stable, immersive, and enjoyable. However, it's difficult to know where to find these great mods, how to install them, and what will be compatible with other mods. My goal with this modlist is to provide a vanilla plus framework with all the modern VR features that can be built on top of with additional Fallout 4 mods.

﻿While other Fallout 4 VR modlists are available, most of them add gameplay modifications that can conflict with how a player may want their game to operate. If a player doesn't like the gameplay mods added, it's difficult to start from scratch since many other mods will need to be removed from the list before it can be rebuilt. This process can also cause issues with custom patches not having masters, and may make the game non-functional if you aren't careful. To provide a good modding foundation, I made this modlist.



<h2>Fallout 4 VR Fundamental Essentials</h2>

This modlist is a fork of Gingas VR's [Fallout VR Essentials](https://www.nexusmods.com/fallout4/mods/96013) version 18.4, but strips it down to just the mods that add VR functionality and bug fixes. If you're looking for a modded hardcore survival experience that is already set up to work with VR, I'd recommend that list instead of this one. This modlist can be used as a simple vanilla plus modlist, or can be used as a foundation for your own personalized list. It also includes three profiles based on how much you want changed from the vanilla game, similar to the [FUS modlist](https://github.com/Kvitekvist/FUS) for Skyrim VR. To see images and more information on the modlist, go to my [Nexus Mods page](https://www.nexusmods.com/fallout4/mods/102510).



<h3>Bare Bones</h3>

This profile includes bug fixes, framework mods, and VR related mods needed to get Fallout 4 VR in a good working state. This profile is best for if you're looking to make your own modlist and just need a good template to start from. It's also great if you just want to play vanilla Fallout 4, but in VR.



<h3>Better Looking Bare Bones</h3>

Same as Bare Bones, but this profile has visual and audio upgrades to make the game look better while retaining a vanilla visual style. It generally has a more gloomy, rusty atmosphere than vanilla, but it isn’t too far off. You can check the images on my [Nexus Mods page](https://www.nexusmods.com/fallout4/mods/102510) to see what it looks like. Not all PCs will be able to handle this since it uses some VRAM heavy textures and includes lighting and weather mods that will impact performance. Any mid range modern gaming PC should be able to handle it though. This profile is best if you want to add in your own gameplay mods, but don’t want to bother with the visuals.



<h3>Bountiful Bones</h3>

This profile is the closest to a complete modlist of the three. This includes all mods from the other two profiles, but also adds several gameplay mods that don’t stray too far from the base game. This profile includes mods for better AI in combat, more difficult progression, and VR based Perk overhaul. Other common modlist additions like new quests, new weapons and armor, or new locations are largely excluded from this modlist. The list is built so that you can decide what additional content you want to install. If you're looking for a vanilla plus modlist that requires no further modding, this is the one for you.
